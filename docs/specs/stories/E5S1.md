# E5S1: Test Clippy Warnings & Code Formatting Hygiene

Eliminate compiler lints in the test suite and repository-wide code formatting drift.

## Acceptance Criteria

1. `cargo clippy --workspace --all-targets -- -D warnings` runs cleanly with zero warnings or errors.
2. All 12 clippy warnings in `crates/qdev-core/tests/` (`config_tests.rs`, `context_tests.rs`, `mcp_tests.rs`) are resolved without disabling lint rules or adding `#[allow(...)]` attributes.
3. `cargo fmt --check` succeeds across the entire repository with zero formatting diffs.
4. All existing tests in `cargo test --workspace` continue to pass without regression.
