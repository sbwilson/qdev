# AD-10: Module Registry With Paths

## Context
Authoritative architectural decision for qdev substrate.

## Decision
Every module referenced by target_modules, impact analysis, preflight scope, or segregation gates is declared in qdev.toml as [[modules]].

* **Rule**: Every module referenced by target_modules, impact analysis, preflight scope, or segregation gates is declared in qdev.toml as [[modules]].
* **Binds**: Boundary enforcement, impact analysis, preflight.
* **Prevents**: Module names with no enforceable meaning.
