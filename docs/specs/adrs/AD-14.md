# AD-14: Cross-Platform by Construction

## Context
Authoritative architectural decision for qdev substrate.

## Decision
macOS, Linux, and Windows are first-class. Process termination uses platform APIs, not signals. Git hooks are two-line shims.

* **Rule**: macOS, Linux, and Windows are first-class. Process termination uses platform APIs, not signals. Git hooks are two-line shims.
* **Binds**: Gate runner, hooks, locking, release packaging.
* **Prevents**: POSIX assumptions that break NFR-101.
