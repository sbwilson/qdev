# AD-13: Stable JSON Envelope and Exit Codes

## Context
Authoritative architectural decision for qdev substrate.

## Decision
Every command supports --json. Success payloads carry schema_version. Errors are emitted as structured JSON on stdout with non-zero exit.

* **Rule**: Every command supports --json. Success payloads carry schema_version. Errors are emitted as structured JSON on stdout with non-zero exit.
* **Binds**: All output paths, skills, MCP tools, CI consumers.
* **Prevents**: Agents scraping text and CI misreading failures.
