# AD-12: Every Command Is Non-Interactive Capable

## Context
Authoritative architectural decision for qdev substrate.

## Decision
Every prompt has a flag equivalent. With --non-interactive or QDEV_NONINTERACTIVE=1, qdev never prompts.

* **Rule**: Every prompt has a flag equivalent. With --non-interactive or QDEV_NONINTERACTIVE=1, qdev never prompts.
* **Binds**: CLI surface, init, overrides, confirmations.
* **Prevents**: Agents and CI hanging on stdin.
