# E5S2: CLI Handler Modularization & Monolith Decomposition

Decompose `crates/qdev-cli/src/main.rs` by extracting monolithic command handlers into modular handlers under `crates/qdev-cli/src/handlers/`.

## Acceptance Criteria

1. Extract `handle_graph`, `handle_doctor`, `handle_sync`, and `handle_schema` from `crates/qdev-cli/src/main.rs` into dedicated modules in `crates/qdev-cli/src/handlers/` (`graph.rs`, `doctor.rs`, `sync.rs`, `schema.rs`).
2. Wire extracted handlers into `main.rs` via `handlers::*`.
3. All CLI tests (`cargo test -p qdev-cli`) pass with zero regressions.
4. `cargo clippy --workspace --all-targets -- -D warnings` and `cargo fmt --check` pass cleanly with zero warnings or diffs.
5. `qdev hygiene check --diff` passes with zero findings.
