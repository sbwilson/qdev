# AD-11: Scratchpads Are Separate, Append-Only, Committed Files

## Context
Authoritative architectural decision for qdev substrate.

## Decision
Each story's scratchpad is a JSONL file under docs/state/scratch/<story-id>.jsonl, committed to Git.

* **Rule**: Each story's scratchpad is a JSONL file under docs/state/scratch/<story-id>.jsonl, committed to Git.
* **Binds**: Scratchpad storage and every projection.
* **Prevents**: Story files bloating and scratchpads being lost on clone.
