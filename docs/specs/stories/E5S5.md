## Acceptance Criteria
1. Pin the post-transition hook lifecycle contract in `crates/qdev-core`: verify through conformance tests in `crates/qdev-core/tests/transition_tests.rs` that `PostTransitionHook` implementations execute after `closes_dw` closure and story state persistence on disk, receiving the exact committed version and state.
2. Clarify error status and diagnostic details when a post-transition hook fails after story updates and DW closures have committed to disk (e.g. reporting `post_transition_hook_failed` with committed version and closed DW details).
3. Wire comment hygiene checking (`qdev_core::hygiene::check_hygiene`) into `crates/qdev-core/src/chore.rs:commit_chore` for all allowlisted files being committed that exist on disk, using the active workspace configuration.
4. Refuse chore commits containing unexempted comment hygiene violations (narrative markers, excessive inline comment lines) with `QdevError::logical_failure("hygiene_failed", ...)` and exit code 1, preventing unhygienic comments from entering the repository via chores.
5. Provide unit and integration tests in `crates/qdev-core/tests/chore_tests.rs` verifying both rejection of unhygienic chore commits and acceptance of clean chore commits.
6. All workspace tests (`cargo test --workspace`), clippy (`cargo clippy --workspace --all-targets -- -D warnings`), formatting (`cargo fmt --check`), and `qdev hygiene check --diff` pass with zero findings.
